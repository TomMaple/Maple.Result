# TemplatedMessage.Equals(TemplatedMessage) Method

Determines whether the specified [TemplatedMessage](TemplatedMessage.md) is equal to the current one, comparing the [Params](TemplatedMessage_Parameters.md) collection by its content rather than by reference.

```csharp
public bool Equals(TemplatedMessage? other);
```

### Parameters
#### `other` [TemplatedMessage](TemplatedMessage.md)
The [TemplatedMessage](TemplatedMessage.md) to compare with the current instance.

### Returns
[Boolean](https://learn.microsoft.com/dotnet/api/system.boolean)

`true` if the specified [TemplatedMessage](TemplatedMessage.md) is equal to the current one; otherwise, `false`.

## Remarks
Two [TemplatedMessage](TemplatedMessage.md) instances are equal when their [TemplateId](TemplatedMessage_TemplateId.md) values are equal and their [Params](TemplatedMessage_Parameters.md) hold the same entries. The parameters are compared **by content**, independent of the order of the entries; values are compared with `object.Equals`.

> [!NOTE]
> The default record equality generated by the compiler would compare the [Params](TemplatedMessage_Parameters.md) dictionary by reference, so two messages built with identical values would be considered *not equal*. This method overrides that behavior to provide value-based equality.

This override is consistent with [GetHashCode()](TemplatedMessage_GetHashCode.md): equal [TemplatedMessage](TemplatedMessage.md) instances always produce the same hash code.

> [!NOTE]
> The values of the parameters are compared with `object.Equals`. Values without value equality (e.g., arrays or most classes) are compared by reference.

## Examples
```csharp
var first = new TemplatedMessage("errors-user-notfound", ("userId", 12345));
var second = new TemplatedMessage("errors-user-notfound", ("userId", 12345));

// true — the messages are compared by value, including their parameters.
var areEqual = first == second;
```
