# MR0002: A task is not awaited by a side effect method

| Property | Value |
| -------- | ----- |
| **Rule ID** | MR0002 |
| **Title** | A task is not awaited by a side effect method |
| **Category** | Usage |
| **Enabled by default** | As error; [not configurable](README.md#configuring-the-rules) |
| **Applicable languages** | C# |
| **Code fix** | Yes, for `IfSuccess`, `IfError` and `Result.Try` |

## Cause
A lambda whose body is an expression of a task type (`Task`, `Task<T>`, `ValueTask` or `ValueTask<T>`), or an `async` lambda, is passed to a parameter of a method of the library that takes an action: a delegate that returns nothing.

## Rule description
`IfSuccess`, `IfError`, `Switch` and `SwitchAsync` take actions, and so does `Result.Try` when its argument is named `action`. A lambda that returns a task converts to an action, and the task is discarded: the method returns before the task completes, and its exception is lost. An `async` lambda converted to an action becomes `async void`.

On a task of a result, `IfSuccessAsync` and `IfErrorAsync` have an overload for a synchronous action too. A function that returns a `ValueTask<TValue>` binds to it today, so its task is not awaited, and the rule reports it. (A function that returns a `Task<TValue>` is awaited, and its value is ignored. On a `Result` or a `Result<T>`, a function that returns a `ValueTask<TValue>` does not compile: CS0029 and CS1662.)

The rule does not report:

* a lambda with a block body, which can discard a task explicitly (e.g., `e => { _ = LogAsync(e); }`);
* a lambda that only throws (e.g., `e => throw new InvalidOperationException(e.Title)`);
* a function that the method awaits (e.g., `result.IfSuccessAsync(x => SaveAsync(x))`).

## How to fix violations
* In `IfSuccess`, `IfError` and `Result.Try`, use `IfSuccessAsync`, `IfErrorAsync` and `Result.TryAsync`, and await the call. The code fix renames the method and awaits the call where that is possible (see [Code fixes](README.md#code-fixes)).
* In `Switch` and `SwitchAsync`, use `Match` or `MatchAsync` with two functions that return a task: `Match` returns the task of the function that ran, and `MatchAsync` awaits it.
* For a function that returns a `ValueTask<TValue>` in `IfSuccessAsync` or `IfErrorAsync`, pass an `async` lambda with a block body that awaits it.
* To start a task without awaiting it on purpose, discard it in a block body: `x => { _ = SaveAsync(x); }`.

## When to suppress warnings
Do not suppress this rule. A task that is started on purpose and not awaited is written as a discard in a block body (e.g., `e => { _ = LogAsync(e); }`), and is then not reported.

## Suppress a warning
The rule is reported as an error and is not configurable: `#pragma warning disable MR0002`, `<NoWarn>` in the project file and a severity in a configuration file have no effect, as for a compile error. See [Configuring the rules](README.md#configuring-the-rules) for what still silences it.

## Examples
### Violations
```csharp
Result<int> ok = Result.FromValue(1);
Task<Result<int>> okTask = Task.FromResult(ok);
Task SaveAsync() => Task.CompletedTask;
Task LogAsync(Error e) => Task.CompletedTask;
ValueTask<string> GetNameValueTask() => new("name");

// MR0002: the task is discarded
_ = ok.IfSuccess(x => SaveAsync());
_ = ok.IfError(e => LogAsync(e));

// MR0002: the lambda becomes async void
_ = ok.IfError(async e => await LogAsync(e));

// MR0002: the task of the error action is discarded
ok.Switch(x => Console.WriteLine(x), e => LogAsync(e));

// MR0002: a ValueTask<string> binds to the overload with a synchronous action
_ = okTask.IfSuccessAsync(x => GetNameValueTask());
```

### Fixes
```csharp
Result<int> ok = Result.FromValue(1);
Task<Result<int>> okTask = Task.FromResult(ok);
Task SaveAsync() => Task.CompletedTask;
Task LogAsync(Error e) => Task.CompletedTask;
ValueTask<string> GetNameValueTask() => new("name");

_ = await ok.IfSuccessAsync(x => SaveAsync());
_ = await ok.IfErrorAsync(e => LogAsync(e));
_ = await ok.IfErrorAsync(async e => await LogAsync(e));

// Match returns the task of the function that ran
await ok.Match(x => SaveAsync(), e => LogAsync(e));

_ = await okTask.IfSuccessAsync(async x => { await GetNameValueTask(); });

// Not reported: the task is discarded on purpose
_ = ok.IfError(e => { _ = LogAsync(e); });
```
